# Study hub: deadlines and reminders across courses

Read-only over the notes except for reminders. Never open Brightspace, never start or answer a quiz.

## What to do
1. List `notes/*/TIMELINE.md`. Read each (plus the course's `MASTER.md` Parked / Reminders list if the user keeps one there).
2. Ask for today's date if you don't have it. Build one table sorted by date: **When | Course | What | Type | Weight | Source file**. Mark **overdue**, **due in 7 days**, and **no date stated**. Use only dates the files state; a week number stays a week number. Never guess a date.
3. Add the user's own items (things they told you, such as "submit the hardcopy to Teams") as a separate **Personal** block with the date they gave.
4. Answer the question asked (what's due today / this week / for course X) first, then the full table.

## Reminders
- You cannot ring the user's phone. Say so once, then offer: a calendar event if a calendar tool is connected (ask before creating it), or keep it in the **Parked / Reminders** list that you repeat at the end of every reply.
- When the user sets a reminder for one course, also tell them it should be added to that course's thread: in Claude Code send it to that course's session quoting the user's words; in Codex give them one line to paste into that course's thread. Never edit another course's notes yourself.
- Dates that conflict between files (calendar vs brief) go in a **To confirm** list with both sources; don't pick one.

## Parked / Reminders
Repeat the user's whole running list at the end of every reply until they finish or drop each item.
